## Учебные проекты

### repair-landing

Учебный mobile-first лендинг для услуги ремонта квартир под ключ в Москве.
Довёл проект до portfolio demo: отработал коммерческую структуру, визуальную полировку,
адаптив, форму заявки, бургер-меню, раскрывающиеся блоки и публикацию через GitHub Pages.
Контент оформлен честно: без фейковых отзывов, реальных клиентов и вымышленных кейсов.

### cleaning-calculator

Учебный mobile-first лендинг клининга квартир в Москве с калькулятором стоимости и времени уборки.
Отработал JavaScript-логику: расчёт цены, состояния формы, граничные значения и frontend-валидацию.
Проект опубликован через GitHub Pages.

### auto-service-catalog

Учебный portfolio demo каталога услуг автосервиса на Astro + TypeScript.
Это следующий шаг после лендинга и калькулятора: статический сайт с file-based routes, каталогом услуг, фильтрами, страницами отдельных услуг и mobile-first интерфейсом.
После миграции с React/Vite проект стал статичнее и легче по клиентскому JavaScript, сохранив доступную многошаговую demo-форму записи: предвыбор услуги, frontend-валидацию, focus trap, закрытие по Escape и возврат фокуса.
Дополнительно отработал визуальную доводку, hash-redirect для старых ссылок и деплой через GitHub Actions на GitHub Pages. Это portfolio demo: без backend, CRM и реальной отправки заявок.

- Код: [github.com/nefrit333-cpu/auto-service-catalog](https://github.com/nefrit333-cpu/auto-service-catalog)

### remont-crm

Учебный fullstack portfolio demo CRM для ремонтной компании на Laravel + Inertia + React + TypeScript.
Это самый сложный проект в портфолио сейчас: после лендинга, калькулятора и Astro-каталога здесь уже есть backend, роли, seed-данные, тесты и проверки зависимостей.
В demo-сценарии отработаны заявки, объекты, задачи, календарь, файлы, платежи, акты, клиенты, команда и настройки.
Проект остаётся demo: без production deploy, реальной CRM-интеграции, настоящей отправки писем и рабочих уведомлений.
Перед публикацией закрыты Composer audit и npm audit.
